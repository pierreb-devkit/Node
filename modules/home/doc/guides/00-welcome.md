# Welcome

Welcome to the API documentation. These guides walk you through what the service does, how to authenticate, and how to make your first request.

The guides are public reference content: no account is required to read them. Each guide is plain markdown — the same source powers the in-app docs, the OpenAPI reference sidebar, and the machine-readable docs feed.

## How the docs are organised

Guides are grouped into categories (for example, **Get Started**). Within a category, guides follow a recommended reading order. Start at the top and work down.

## Where to go next

When you are ready to make your first call, head to the **Quickstart** guide. It shows you how to send an authenticated request and read the response envelope.
